# Lumia 插件系统设计 v3（Lumi 语言定稿）

> 状态：设计定稿。语言风格由作者本人手写样例确定（类 Python 缩进式、极简英文、无多余符号）。
> 目标版本：v1.1（插件系统为 v1.0 之后的首个大功能）

---

## 1. 定位

- 插件 = 一个 `.lplugin` 压缩包（zip 改后缀），内含 `main.lumi` 主文件 + 资源文件，丢进 `plugins/` 即识别。
- **三种形态**：`.lplugin` 压缩包 / `plugins/<id>/` 文件夹（含 `main.lumi`）/ **单文件 `plugins/<id>.lumi`**。单文件无任何资源也能正常解析运行；图标缺省时前端默认显示 `plugin.svg`。单文件因无资源/无图标过不了插件市场审核，但本地加载**不拦**。
- 语言「Lumi」：类 Python 缩进式，极简英文关键词，无变量类型声明、无复杂语法。**零编程基础可读懂，VSCode 补全友好，AI 可以代写。**
- 运行模型：插件代码由 Rust 解释器直接执行（无 iframe 沙箱——语言本身没有逃逸能力）。UI 由解释出的控件树驱动前端渲染。

## 2. 语言规范（作者亲写样例 = 定稿基线）

### 2.1 完整示例（作者亲写语法 = 定稿基线）

```
# 自动备份插件示例（作者原样语法：单行括号表达式）
name: Auto Backup
version: 1.0
description: 退出游戏后自动备份存档
icon: icon.png

Backup_Button = CreateButton('立即备份')
Backup_Button.center
Status_Text = CreateText('等待中')

listen Backup_Button.click:
    copy game-saves to backup-folder
    Status_Text = '备份完成'

listen game_quit:
    copy game-saves to backup-folder
    popup('游戏被退出了，已自动备份')
```

> 说明：**交互一律用 `listen 控件.事件`**（事件驱动，不轮询）。`press`（按住）/`click`（单击）是按钮事件，不属于 `if` 条件。
>
> 单行括号式与缩进块式两种写法等价：`listen X.click(动作)` ≡ `listen X.click:` + 缩进块。

### 2.1b 两种事件写法定稿

```lumi
# 第一种：单行括号式（推荐，作者原语法）
listen 按钮.click(动作A; 动作B)
listen 按钮.press(动作C)

# 第二种：缩进块式（Python 习惯者）
listen 按钮.click:
    动作A
    动作B

# 注意：两种形式不能混用在同一 listen 里。
```

### 2.2 元信息（文件头）

```
name: 插件名
version: 版本号（如 1.0 / 1.2.3）
description: 一句话说明
icon: 图标文件名（如 icon.png）
min: 最低启动器版本（可选）
```

### 2.3 控件（UI 声明 + 交互）

```
名字 = CreateButton('按钮文字')
名字 = CreateText('文本')
名字 = CreateInput('默认值')
名字 = CreateList('项1', '项2', ...)      # 列表，选中可查
名字 = CreateToggle('开关标签')
名字 = CreateImage('图片文件名')
名字 = CreateLine()                  # 分隔线：默认贯穿整行宽度的横线
名字 = CreateLine(500)               # 长度 500px 的横线
名字 = CreateLine(500, portrait)     # 500px 的竖线 (portrait = 竖)

# 布局（默认靠左）
名字.left / 名字.center / 名字.right

# 更新显示内容（文本/输入框/按钮文字都可）
名字 = '新内容'

# 列表/下拉选中项的读取
名字 is select                             # 查是否有选中
名字.selected                              # 取选中项内容
```

### 2.4 条件（if）

交互不走 if：按钮等控件的按下/点击**一律用 listen**（见 2.6）。`if` 只用于**非交互判断**：

```
# 单行括号式（作者原语法）
if 条件(动作1; 动作2)

# 缩进块式
if 条件:
    动作1
else:
    动作2

# 条件本身（不含 press/click/hover——那些是事件，不是条件）
条件 = 控件 is select                       # 列表/下拉有选中项
     | 控件.selected == '某某'              # 选中项内容比较
     | 字符串相等比较
```

无 `elif`（嵌套 if 代替），无 else-if 链——保持最简单。

### 2.5 循环

```
while:            # 无限循环，解释器每轮自动 sleep 50ms 防占满 CPU
    ...
for 项 in 列表:   # 遍历列表控件的内容 / 遍历列表字面量
    ...
for i in 1..5:    # 数字区间（1,2,3,4）
    ...
for i in 0..10:   # 到 10（左闭右开：0..9）
    ...
for i in 1..5 step 2:   # 步长 2（1,3,5）
    ...
```

- 遍历对象：**列表控件**（`CreateList(...)` 的内容）、**列表字面量**（`('a', 'b', 'c')`）、**数字区间** `数字..数字`（整数递增）。
- `break` 立即退出循环；无 `continue`（保持最简单；需要跳过就用 `if 条件(...)` 包裹）。
- 循环体内可用 `项` 直接传给动作/比较：`copy 项 to backup-folder`。

### 2.6 事件监听（异步，不阻塞 while）

**两类事件**：系统事件 + 控件事件。事件触发即执行块（或单行括号动作），
与 while 主循环相对独立（启动器统一调度）；listen/while/if 持续运行直到插件被停用。

```
# 控件事件（按钮交互，事件驱动，不轮询）
listen 控件.click:
    ...
listen 控件.press:
    ...
listen 控件.hover:
    ...

# 系统事件
listen game_quit:      # 游戏退出（真实钩子 P1 接）
listen game_start:     # 游戏启动（P1 接）
listen game_crash:     # 游戏崩溃（P1 接）
listen version_install:# 安装完版本（P1 接）
listen version_download_start:   # 版本下载开始（P1 接）
listen version_download_finish:  # 版本下载完成（P1 接）
listen download_finish:# 下载任务完成（P1 接）
listen download_fail:  # 下载失败（P1 接）
listen app_launch:     # 启动器启动（P1 接）
listen app_close:      # 启动器关闭（P1 接）
listen terracotta_join:# 联机房间加入（P1 接）
listen music_toggle:   # 音乐播放/暂停切换（P1 接）
```

### 2.7 动作库（全部由 Rust 实现，即白名单）

| 动作 | 作用 | 示例 |
|---|---|---|
| `copy A to B` | 复制文件/目录 | `copy game-saves to backup-folder` |
| `move A to B` | 移动 | `move 'out.zip' to backup-folder` |
| `delete A` | 删除（进回收站） | `delete backup-folder` |
| `open A` | 打开文件夹/文件 | `open backup-folder` |
| `popup('文字')` | 弹窗提示 | `popup('备份完成')` |
| `toast('文字')` | 右下角轻提示 | `toast('已保存')` |
| `sleep 秒数` | 等待（数字） | `sleep 1` |
| `launchGame()` | 启动当前游戏版本（需权限，可选） | — |
| `mkdir 路径` | 创建目录（可多级，已实现） | `mkdir 'logs'` |
| `exists 路径` | 判断路径是否存在，toast 反馈（已实现） | `exists game-saves` |
| `listFiles 路径` | 列出目录内容，toast 反馈（已实现） | `listFiles plugin-dir` |

### 2.8 内置名词（不用写路径）

| 名词 | 指代 |
|---|---|
| `game-saves` | 当前版本的存档目录 |
| `backup-folder` | 插件自己的备份目录（启动器自建） |
| `game-dir` | 游戏根目录 |
| `plugin-dir` | 插件自己的目录 |
| `today` | 今天的日期字符串（如 `2026-08-22`） |
| `versions-dir` | 版本目录（<data>/versions，已实现） |
| `launcher-dir` | 启动器数据根目录（已实现） |
| `music-dir` | 音乐库目录（<data>/music_library，已实现） |

自定义路径写字符串：`copy 'saves/myworld' to backup-folder`。

### 2.9 注释与语法细节

- 注释：`#` 或 `//` 直到行尾，均可。
- 缩进：4 空格（Tab 也接受，统一按空格解释）。
- 字符串：单引号或双引号。
- **没有**：函数定义、参数、变量类型、算术运算符（除字符串拼接 `+` 之外）、复杂控制流。
- 错误处理：解释器每「动作/块」包错误边界，出错 → 中文错误 toast（如 `第 12 行：备份目录不存在`），不崩启动器。

### 2.10 权限模型（零配置）

无权限声明，安全靠**动作词白名单**：语言只能做上面动作库列的事，不能读任意文件（copy/read 受限于内置名词与插件自己的目录，路径 canonicalize 校验防 `../`），不能访问网络，不能改启动器样式。写 `game-dir` 外的任意路径默认拒绝。

## 3. `.lplugin` 包格式

```
plugins/
└── autosave.lplugin          # zip 改后缀
    ├── main.lumi             # 主文件（上面的语言）
    ├── icon.png
    └── assets/...            # 页面里引用的图片等
```

识别流程（启动时 + 插件中心手动刷新）：扫描 `plugins/` 下三类形态（`.lplugin` 包 / `<id>/` 文件夹 / `<id>.lumi` 单文件）→ 解析源码 → 生成控件树 → 注册页面与事件。解析失败记日志，不崩启动器。

## 7. 运行时架构

```
扫描 plugins/*.lplugin → 解压 → 解析 main.lumi → 控件树 + 事件表 + 动作表
主界面：PluginPage.vue 按控件树渲染（按钮/文本/输入/列表/开关/图片）；PluginCenter.vue 管理页（启停/删除/打开目录/控件预览/刷新）
交互：按钮点击 → 前端 postMessage → Rust 解释器触发对应 listen 事件块
事件：Rust 侧（游戏退出等钩子）→ 触发 listen 块（在新执行上下文，不阻塞主循环）
```

`App.vue`：`navItems` 合并插件注册的页面入口；`ViewType` 增加 `'plugin'`。

## 附：P0 实现状态（Rust 解释器 + 前端插件页）

> 本阶段已完成端到端运行链路，与上文语言规范一致。下文仅记录实现时的落地细节与占位。

### 控件事件全集（listen 控件.事件）
| 事件 | 触发时机 |
|------|----------|
| `click` | 按钮/文本等点击 |
| `press` | 按住（前端暂发 click，P1 区分按下/抬起） |
| `hover` | 悬停（P1 接入） |
| `change` | 列表/输入框值变化 |
| `check` / `uncheck` | 开关切换 |
| `input` | 输入框输入 |

### 系统事件（listen 系统事件名）
`game_quit` / `game_start` / `version_install` / `download_finish` / `app_launch`
—— P0 已注册事件分发通道，真实钩子接线在 P1（目前可由插件 `listen game_quit:` 等直接写入，等待启动器对应时刻触发）。

### 内置名词（P0 落点）
| 名词 | P0 实际路径 | 说明 |
|------|-------------|------|
| `game-dir` | `<app_data>` | P1 指向当前版本目录 |
| `game-saves` | `<app_data>/saves` | P1 指向当前版本 saves |
| `backup-folder` | `<plugin-dir>/backup` | 自动创建 |
| `plugin-dir` | `<app_data>/plugins/<id>/` | 插件自身目录 |
| `today` | Unix 时间戳 | P1 换可读日期 |

### 运行时语义（与规范 2.6 对齐）
- 顶层 `listen` → 注册为事件处理器；事件触发时执行对应块（P0 已接通前端交互 → 后端）。
- 顶层 `while:` → 独立后台任务，每轮执行循环体一遍 + sleep 50ms。
- 顶层 `if:` → 每 50ms 评估一次（持续运行语义）；块内 `if` 正常执行一次。
- 块内 `while` 只执行一遍（避免卡死事件分发；常驻循环请写在顶层）。
